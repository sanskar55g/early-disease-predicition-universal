# early-disease-predicition-universal
An end-to-end AI platform for disease prediction and differential diagnosis — combining supervised ML models (Tier 1), symptom classifiers (Tier 2), knowledge-graph reasoning via SNOMED/ICD/UMLS (Tier 3), and rare-disease phenotype matching via HPO/Orphanet (Tier 4) into a single explainable, evidence-tagged report.
